# 放松漂浮 · Floatwave

极简白噪音与专注计时器。打开就用，不需要账号，不上传任何数据。

## 四个版本

| 版本 | 适合 | 四种声音 |
|---|---|---|
| **水域** | 专注、放空 | 水声一 · 湖浪 · 溪流 · 雨声 |
| **清风** | 阅读、休息 | 微风 · 钟声 · 金属风铃 · 树林 |
| **夜色** | 入睡 | 篝火 · 夜雨 · 烛火 · 夜风 |
| **ASMR** | 放松、助眠 | 摩擦 · 轻敲 · 果壳 · 泡沫 |

## 怎么用

- 时长四档：五分钟 / 一刻 / 两刻 / 三刻
- 音量滑杆独立于系统音量
- 到点淡出，并轻响两声提示
- 换声音即时生效，不需要重新开始

## 兼容

Chrome、Safari、Edge 的桌面与移动端。

iOS 锁屏后系统会挂起网页音频，这是系统限制，不是页面问题。

## 隐私

没有广告、没有统计脚本、没有第三方请求。所有声音都在本地生成；水域版的雨声和 ASMR 版的果壳铃是内嵌在文件里的录音，不联网加载。

## 构建流程

**水域版和 ASMR 版含内嵌音频，不能直接编辑成品。**

源文件在 `~/Desktop/白噪音系列/源文件/`：

| 模板 | 构建命令 | 产物 |
|---|---|---|
| `breathing-timer.html` | `bun build-rain.js rain80.m4a <输出>` | 水域版（雨声 60 秒） |
| `asmr-timer.html` | `bun build-shell.js shell80.m4a <输出>` | ASMR 版（果壳铃 120 秒） |

模板里的占位符分别是 `__RAIN_B64__` 和 `__SHELL_B64__`。直接编辑成品会导致下次构建时改动丢失。

清风版和夜色版是纯合成，没有音频文件，可以直接编辑。

## 更新步骤

1. 改 `~/Desktop/白噪音系列/源文件/` 里的模板
2. 需要音频的版本跑构建命令
3. 把产物复制成对应的 `index.html`
4. 本地打开验证，再提交
